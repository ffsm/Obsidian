# Fluxo SDD

## Ordem dos Comandos

| # | Comando | Quando usar |
|---|---------|-------------|
| 1 | `/speckit-constitution` | Uma vez por projeto — princípios imutáveis |
| 2 | `/speckit-specify` | Sempre primeiro — o que construir |
| 3 | `/speckit-clarify` | Opcional — perguntas de de-risco |
| 4 | `/speckit-plan` | Como construir |
| 5 | `/speckit-tasks` | Quebrar o plano em tarefas atômicas |
| 6 | `/speckit-implement` | Executar as tasks |
| 7 | `/speckit-converge` | Verificar se o código bate com a spec |

## Regra de Ouro
Edite a **spec** antes de codar. Quando requisito muda, atualize a spec primeiro.

## Artefatos Gerados
- `constitution.md` — princípios do projeto
- `spec.md` — especificação (o quê)
- `plan.md` — plano de implementação (como)
- `tasks.md` — tarefas atômicas
- `data-model.md` — modelo de dados
- `quickstart.md` — guia de início
- `research.md` — pesquisa técnica
